StellarHR Solutions - Onsite - Post Demo Scope Analysis

StellarHR Solutions handles One-off & Retainer clients.

They have SLA's with Clients that determine the HR Functions they should carry out.

StellarHR will provide the above HR Functions.

These functions are recurrent for all customers with the same SLA's.

Most functions/tasks have defined subtasks.

Tasks for defined functions SHOULD be dependent on each other.

HR Associate should handle multiple Client Projects.

1\. On site projects, where they must check in

2\. Off-site projects where an associate doesn't need to check in to carry out tasks.

For the Off-site projects, the tasks they handle should show the Geo-Location where they handled the

tasks.

All Tasks and its attached activities should notify the Assignee immediately.

For every Task, the Assignee should have a section to provide feedback/comment.

Tasks have specific required files to be attached.

Let's ensure this is configurable at the Task Level.

Only the project manager should be able to assign its tasks to other HR Associates.

The progress of a task should always be attached to the relevant assignee who executed it.

They have flexible Work Schedules:

Day Shifts

Night Shifts

The accountability of the 8hrs cycle is key for visibility and reporting.

For Reporting Purpose, the view of Projects should be as follows:

Client Project

\-​ HR Function

\-​ Task(s) under HR Function - with Status and Progress (If not complete, let it show an

overview of what is pending)
